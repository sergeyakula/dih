## Как получить токены

1. Добавьте сеть Sepolia в MetaMask и получите немного SepoliaETH из крана для оплаты газа.
2. Попросите владельца отправить вам DIH (или DN) на ваш адрес. Владелец DIH: `0x35C0…8871`.
3. В MetaMask: Import tokens → вставьте адрес контракта. Или нажмите «Добавить в MetaMask» на дашборде.
4. DIH также можно купить за SepoliaETH в пуле Uniswap (см. ниже).

## Как устроен дашборд

| Файл | Что делает |
| --- | --- |
| `index.html` | разметка и стили |
| `app.js` | вся логика: ethers.js v6 (`BrowserProvider`, `Contract`), чтение `name/symbol/decimals/totalSupply/balanceOf`, перевод через `transfer()` |
| `vendor/ethers-6.13.4.umd.min.js` | библиотека ethers.js v6 (локальная копия, без внешнего CDN) |
| `contracts/DIHCoin.sol` | исходный код токена DIH |

Проверки перед отправкой (до любого запроса в MetaMask):

- адрес получателя проверяется через `ethers.isAddress`; нулевой адрес и собственный адрес отклоняются;
- количество переводится в базовые единицы через `ethers.parseUnits(amount, decimals)`, где `decimals` читается из контракта, а не задаётся вручную;
- нулевое, отрицательное, нечисловое количество и количество больше баланса отклоняются с понятным сообщением;
- сеть проверяется прямо перед отправкой. Если это не Sepolia, перевод блокируется и предлагается переключить сеть.

После подписи дашборд ждёт receipt (`tx.wait()`). Только при `status = 1` показывает успех и перечитывает балансы из блокчейна. Отмена в MetaMask показывается как «Транзакция отменена», успех при этом не объявляется. Страница не содержит полей для приватного ключа или seed-фразы.
