## Как получить DIH

Весь выпуск при деплое поступает на кошелёк, который развернул контракт. Чтобы получить DIH, попросите владельца отправить токены на ваш адрес в сети Sepolia, затем добавьте токен в MetaMask по адресу контракта (Import tokens).

## Файлы

- `contracts/DIHCoin.sol`: исходный код контракта
- `index.html`: страница, которая подключает MetaMask, деплоит контракт, показывает баланс DIH и отправляет токены. Проверяет адрес, сумму, баланс и сеть; не запрашивает seed-фразу или ключи.

Только тестовая сеть. Токен не имеет реальной ценности.
